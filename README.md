### [Automated_ETL_API_to_DB](Automated_ETL_API_to_DB/)

**Описание:**  
Скрипт для загрузки данных из API, их очистки и обработки, а затем загрузки в базу данных PostgreSQL.

- 💻 **Языки и технологии:** Python 3, библиотека requests для работы с API, pandas для обработки и трансформации данных, psycopg2 для взаимодействия с PostgreSQL, JSON для работы с конфигурациями, PyInstaller для создания исполняемого файла `.exe`.  
- 🔍 **Как использовать:** Для запуска скрипта необходимо настроить конфигурационные файлы, создать виртуальное окружение и установить зависимости.  
- 📄 [Подробнее о проекте в `README`](Automated_ETL_API_to_DB/README.md)

## Как использовать данные в репозитории

1. Клонируйте репозиторий:  
```sh
git clone https://github.com/leonboroz/Portfolio
```

2. Перейдите в папку проекта:
sh
   cd Portfolio
Для каждого проекта в папке есть отдельные инструкции по установке и запуску в соответствующих README.md файлах внутри каталога проекта.
