# 🌤️ Found

`Found` — Python-скрипт для определения города с самой высокой температурой из заданного списка, используя два открытых API:

- 🌍 [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) — для получения координат города.
- 🌡️ [Open-Meteo](https://open-meteo.com/) — для получения текущей температуры по координатам.

---

## 🚀 Установка и запуск

1. Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate     # Linux/macOS
venv\Scripts\activate        # Windows
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```
3. Запустите скрипт

```bash
from Found import WeatherAnalyzer
```

cities = ['Москва', 'Париж', 'Лондон', '123', 'Москв']
wa = WeatherAnalyzer(cities)
wa.run()

⚙️ Описание

get_geo() — получает координаты городов через OpenStreetMap.

get_temp() — получает текущую температуру по координатам через Open-Meteo.

run() — выполняет оба шага и выводит город с максимальной температурой.

✅ Обработка ошибок

Пропускает некорректные города.

Обрабатывает ошибки сетевых запросов и парсинга данных.

Не прерывает выполнение при ошибках.
