Для визуализации приму следующие:
1. Общая динамика продаж по месяцам
— Суммарные продажи всех клиентов и товаров — чтобы видеть общий тренд по бизнесу

2. Динамика покупок клиентов по месяцам после активации карт
— Покажи, как клиенты (VIP и обычные) покупали на протяжении года после розыгрыша.
— Можно сделать фильтр по сегменту клиента.

3. Распределение покупателей по VIP и обычным клиентам
— Количество клиентов и доля продаж по сегментам.

4. Использование подарочных карт: объем потраченных средств по месяцам
— Как активно использовались карты после активации.

5. Топ-4 товаров по продажам с разбивкой по месяцам
— Сравнение спроса на товары и тренды.

6. Закупки у поставщиков: распределение по объему и поставщикам
— Объем закупок по каждому поставщику.

7. Клиентская лояльность: количество повторных покупок по сегментам
— Как часто клиенты возвращаются за покупками.
